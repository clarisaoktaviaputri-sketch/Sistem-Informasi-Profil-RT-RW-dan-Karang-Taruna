# 🏘️ Sistem Informasi Profil RT/RW dan Karang Taruna

Sistem Informasi berbasis web yang dirancang untuk mempermudah pengelolaan informasi, kegiatan, dan transparansi keuangan di lingkungan RT/RW serta organisasi Karang Taruna. Web ini mengusung konsep **Public Portal** (dapat diakses bebas oleh warga tanpa login) dan **Admin Panel** (khusus pengurus untuk mengelola konten).

## ✨ Fitur Utama

### 🌐 Halaman Publik (Tanpa Login)
- **Beranda:** Menampilkan ringkasan informasi, statistik warga/anggota, berita terbaru, dan agenda mendatang.
- **Profil RT/RW:** Informasi visi, misi, sejarah, dan struktur pengurus RT/RW serta Karang Taruna.
- **Berita & Pengumuman:** Daftar berita terbaru seputar kegiatan lingkungan.
- **Agenda Kegiatan:** Jadwal kegiatan RT maupun Karang Taruna.
- **Laporan Warga:** Warga dapat mengirimkan laporan masalah lingkungan (misal: lampu mati, jalan rusak) langsung melalui form tanpa perlu membuat akun.
- **Pendaftaran Anggota:** Formulir untuk warga yang ingin bergabung dengan Karang Taruna.
- **Transparansi Kas:** Halaman publik untuk melihat laporan pemasukan dan pengeluaran Kas RT dan Kas Karang Taruna.

### 🔐 Halaman Admin (Memerlukan Login)
- **Kelola Berita:** Tambah, edit, dan hapus berita.
- **Kelola Agenda:** Atur jadwal kegiatan RT dan KT.
- **Kelola Laporan:** Memantau laporan warga dan mengubah status (Baru, Diproses, Selesai).
- **Kelola Kas:** Mencatat pemasukan dan pengeluaran untuk Kas RT dan Kas KT.
- **Kelola Anggota:** Manajemen data anggota Karang Taruna.

## 🛠️ Teknologi yang Digunakan
- **Bahasa Pemrograman:** PHP (Native)
- **Database:** MySQL / MariaDB
- **Frontend:** HTML5, CSS3 (Custom UI), JavaScript dasar
- **Environment Development:** Laragon
- **Version Control:** Git & GitHub
